# PPOMS Web系统 - 开发路线图 (Roadmap V2.0)

## Phase 1: 基础设施与单机功能平移 (Week 1-3)
**目标**: 搭建 Web 框架，将现有 PPOMS-local (PySide6) 的核心数据结构和逻辑完整迁移到 Web 端，单机/单租户运行。

*   [ ] **基础架构**: 初始化 Spring Boot + Vue 3 + Element Plus 项目。
*   [ ] **数据库迁移**: 将 SQLite 结构迁移为 MySQL 8.0 表结构（月度计划、采购计划主单/明细、自动编号逻辑）。
*   [ ] **前期模块**: 实现月度计划导入与管理、采购计划（支持智能推荐字典）、计划发放与导出。
*   [ ] **执行模块**: 平移计划进度面板（Echarts 替代 matplotlib）、合同管理与入库管理（状态自动联动）。
*   [ ] **扩展功能**: 集成内嵌 Markdown 渲染（操作手册平移），实现 CLI 接口在 Web 端的等价 REST API 或 WebSocket 终端。

## Phase 2: 多用户与权限体系增强 (Week 4-5)
**目标**: 将系统从单机模式升级为企业级多用户协作平台。

*   [ ] **RBAC体系**: 实现用户管理、角色管理、部门管理、菜单权限分配。
*   [ ] **认证授权**: Spring Security + JWT 登录流程。
*   [ ] **数据隔离**: 实现采购员只能查看/操作自己被分配的任务，经理查看部门全局数据。
*   [ ] **审批工作流**: 引入轻量级工作流（如 Camunda/Flowable）或硬编码状态机，实现在线审批审批节点流转。

## Phase 3: AI 深度集成与扩展 (Week 6-7)
**目标**: 将目前的 AI 问答升级为具备上下文感知的 Agent 模式。

*   [ ] **多模型网关**: 将 DeepSeek、Kimi、OpenAI、Ollama 的 API 接入统一的后端网关。
*   [ ] **知识库 (RAG)**: 引入向量数据库 (Milvus/PgVector)，支持采购制度 PDF/Word 文件的解析与问答。
*   [ ] **智能报表**: Text-to-SQL，用户在 Web 端输入自然语言自动生成采购分析报表。

## Phase 4: 财务与供应链延伸 (Week 8-9)
**目标**: 补全供应链后半段流程，打通财务对账闭环。

*   [ ] **发票与对账**: 供应商发票录入、入库单关联对账。
*   [ ] **供应商管理**: 供应商档案、评级打分体系。
*   [ ] **结算管理**: 付款申请流程与结算记录追踪。

## Phase 5: 测试、优化与发布 (Week 10)
**目标**: 生产环境上线与交付。

*   [ ] **测试**: 接口并发测试、SIT 集成测试。
*   [ ] **部署**: Docker 容器化部署、Jenkins/GitLab CI/CD 自动化流水线。
*   [ ] **培训与文档**: 基于系统内置操作手册进行全员培训。
