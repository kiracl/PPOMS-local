# PPOMS Web系统 - 全局错误码字典 (Error Codes)

## 1. 响应结构
所有接口统一返回格式：
```json
{
  "code": 200,      // 业务状态码
  "msg": "操作成功", // 提示信息
  "data": { ... }   // 数据载荷
}
```

## 2. 状态码段分配

| 码段 | 模块 | 说明 |
| :--- | :--- | :--- |
| **200** | 成功 | 请求处理成功 |
| **4xx** | 客户端错误 | 参数错误、认证失败 |
| **5xx** | 服务端错误 | 系统异常、数据库错误 |
| **10xxx** | 通用业务 | 字典、文件、系统配置 |
| **20xxx** | 用户权限 | 用户、角色、菜单 |
| **30xxx** | 采购业务 | 计划、订单、任务 |
| **40xxx** | 供应链 | 入库、库存、供应商 |
| **50xxx** | 财务 | 发票、对账、结算 |

## 3. 详细错误码

### 3.1 通用错误 (Global)
*   `200`: 操作成功
*   `400`: 请求参数错误 (Bad Request)
*   `401`: 未授权，请登录 (Unauthorized)
*   `403`: 拒绝访问，无权限 (Forbidden)
*   `404`: 资源未找到 (Not Found)
*   `500`: 系统内部错误 (Internal Server Error)

### 3.2 用户与权限 (Auth & User)
*   `20001`: 用户名或密码错误
*   `20002`: 验证码错误或已失效
*   `20003`: 账号已被禁用
*   `20004`: 旧密码错误
*   `20005`: 两次输入密码不一致

### 3.3 采购业务 (Purchase)
*   `30001`: 采购计划状态不支持该操作 (如已审批计划不可修改)
*   `30002`: 订单金额超过预算限制
*   `30003`: 必须先关联采购任务才能生成订单
*   `30004`: 订单明细不能为空

### 3.4 供应链 (Supply)
*   `40001`: 入库数量不能大于订单剩余数量
*   `40002`: 供应商不存在或已停用
*   `40003`: 仓库编号已存在

### 3.5 财务 (Finance)
*   `50001`: 发票金额与入库金额不匹配
*   `50002`: 该发票已关联其他入库单
*   `50003`: 对账单已确认，无法修改

## 4. 前端处理规范

*   **200**: 正常解析 `data`。
*   **401**: 清除 Token，强制跳转登录页。
*   **其他非200**: 统一拦截，弹出 `ElMessage.error(msg)`，并阻断后续 `.then()` 执行。
