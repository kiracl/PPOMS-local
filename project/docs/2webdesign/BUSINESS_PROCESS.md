# PPOMS Web系统 - 核心业务流程与功能设计 (V2.0)

## 1. 采购前期管理

### 1.1 月度预算与计划 (Monthly Plan)
1.  **计划导入与管理**:
    *   **输入**: Excel 批量导入或手动录入.
    *   **字段**: 计划月份, 需求部门, 物资名称, 规格型号, 预算金额, 备注.
    *   **执行监控**: 系统自动将月度计划与下游的“采购需求明细”进行匹配（基于月份+标的+规格），实时计算执行数量和执行金额，提供可视化进度条。

### 1.2 采购需求录入与审批报告 (Purchase Request)
1.  **需求录入**:
    *   **角色**: 录入员 (各部门)。
    *   **操作**: 录入本部门的采购需求（主单+明细结构）。
    *   **自动编号**: 区分民品(MP)、机加件(MPJ)、半成品(MPB)，各自独立流水号递增。
    *   **核心字段**: 主单级别必须包含 **“审批报告”** 字段，用于上传经过线下审批的 PDF 文件。必须上传后才能提交给采购部。
    *   **状态流转**: 草稿 -> 待审核 (提交给采购经理)。
    *   **智能联动与推荐**: 基于预设知识库，输入物资名称自动带出历史默认的采购方式和权重。
    *   **权限限制**: 录入员只能看到自己录入的数据，部门经理可以看到本部门所有数据。
2.  **CLI 接口 (极客模式)**:
    *   **功能**: 支持通过命令行直接调用后端逻辑生成计划。

### 1.3 计划审核与分配 (Plan Release)
1.  **需求审核与修改**:
    *   **角色**: 采购经理 (生产管理部)。
    *   **操作**: 采购经理具有全局视角，可查看所有部门提交的“待审核”需求。在审核阶段，采购经理可以根据实际情况**修改明细内容**，或者**重新上传最新的审批报告**。可以进行退回操作（退回给录入员）。
2.  **任务分配与发放**:
    *   **操作**: 采购经理将审核通过的计划明细，逐一或批量分配给具体的采购员。
    *   **状态流转**: 待审核 -> 待分配 -> 已分配(未发放) -> 确认分配并点击“发放”后，该批次计划正式进入采购员的任务池。
    *   **打印风格要求**: Web 端打印必须延续单机版风格，隐藏系统导航菜单，仅显示核心数据表格，保持黑白极简风格，表格头部带有分组背景色。

## 2. 采购执行与进度管理

### 2.1 采购员任务池与进度跟踪
1.  **任务池视图**:
    *   **角色**: 采购员 (生产管理部)。
    *   **展示逻辑**: 采购任务依然按照“主单 -> 明细”的树形层级展示，但**明细中只包含已发放且分配给该采购员自己的记录**。
    *   **可见性隔离**: 采购经理尚未点击“发放”的计划单（无论是否已分配采购员），对所有采购员均绝对不可见。
2.  **批量状态更新**:
    *   **操作**: 采购员可勾选自己的明细记录，进行状态更新。支持填写跟进备注。
    *   **状态节点**: 
        *   点开新记录 -> 自动更新为 **“跟进中”**。
        *   已联系供应商 -> 更新为 **“采购中”**。
        *   物资到货 -> 更新为 **“已入库”**。
    *   **闭环逻辑**: 当某条明细状态变为“已入库”时，即标志着该条采购计划已完成。
    *   **部门联动**: 录入员和各部门经理可以实时看到这些明细的进度更新。

### 2.2 合同管理 (Contract Management)
1.  **合同台账**:
    *   **功能**: 录入合同基本信息（编号、金额、供应商）及合同包含的物资明细与总数量。
2.  **执行订单生成**:
    *   **逻辑**: 基于合同明细开具具体的“执行订单”，系统自动扣减合同剩余可执行数量，防止超额执行。

### 2.3 入库管理 (Inbound Management)
1.  **到货登记**:
    *   **操作**: 针对执行订单进行入库数量登记。
2.  **状态自动流转**:
    *   **联动逻辑**: 入库数=0（新增） -> 0<入库数<总数（部分入库，蓝色） -> 入库数>=总数（已入库，绿色）。反向实时更新订单状态。

## 3. 辅助与支持系统

### 3.1 智能 AI 助手 (AI Assistant)
1.  **多模型支持**:
    *   **引擎**: 支持 DeepSeek, Moonshot (Kimi), OpenAI, Ollama (本地部署), 及自定义大模型。
2.  **业务赋能**:
    *   **功能**: 悬浮式对话窗口，解答系统操作问题，提供采购专业建议，辅助数据分析。

### 3.2 帮助与文档 (User Manual)
1.  **内置操作手册**:
    *   **形式**: 系统内嵌 Markdown 渲染引擎。
    *   **功能**: 左侧目录树，右侧富文本展示系统使用教程、CLI 指令大全及业务规范。

### 3.3 数据安全 (Data Management)
1.  **备份与恢复**:
    *   **功能**: 一键备份本地 SQLite 数据库，支持历史备份点的无缝恢复，恢复前自动执行快照保护。
