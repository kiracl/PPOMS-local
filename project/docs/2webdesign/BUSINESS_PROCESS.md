# PPOMS Web系统 - 核心业务流程与功能设计 (V1.0)

## 1. 采购管理模块

### 1.1 采购计划 (Monthly Plan)
1.  **新建计划**:
    *   **角色**: 生产部文员/主管.
    *   **输入**: Excel 导入或手动录入.
    *   **字段**: 月份, 部门, 物资名称, 规格型号, 单位, 数量, 预算, 备注.
    *   **状态**: 草稿 -> 待审批 -> 已审批 -> 执行中 -> 已完成.
2.  **计划审批**:
    *   **角色**: 采购经理/总经理.
    *   **操作**: 同意/驳回.
    *   **逻辑**: 审批通过后，生成 `PurchaseTask` (待办任务) 推送给采购部.

### 1.2 采购任务分配 (Purchase Task)
1.  **任务池**: 展示所有审批通过的采购计划明细.
2.  **分配任务**:
    *   **角色**: 采购经理.
    *   **操作**: 勾选任务 -> 指派给具体的 `采购员` (Purchaser).
    *   **状态**: 待分配 -> 采购中.

### 1.3 询价与定点 (Price Inquiry)
1.  **发起询价**:
    *   **角色**: 采购员.
    *   **操作**: 选择任务 -> 填写 `询价记录` (供应商, 报价, 账期).
    *   **辅助**: 系统自动展示该物资的历史最低价、最高价、平均价 (AI 价格建议).
2.  **定点审批**:
    *   **角色**: 采购经理.
    *   **操作**: 审核询价结果 -> 确认最终供应商与价格.

### 1.4 采购订单 (Purchase Order)
1.  **生成订单**:
    *   **角色**: 采购员.
    *   **操作**: 基于定点结果生成正式采购订单.
    *   **字段**: 订单号, 供应商, 签订日期, 交货期, 明细 (物资, 数量, 单价, 总价).
2.  **合同管理**:
    *   **逻辑**: 若订单金额较大，可关联或生成 `采购合同`.
    *   **功能**: 合同台账、付款节点提醒、附件上传.

## 2. 供应链管理模块

### 2.1 入库管理 (Inbound)
1.  **到货登记**:
    *   **角色**: 库管员.
    *   **操作**: 扫描订单号/手动选择订单 -> 录入实收数量.
    *   **逻辑**:
        *   支持分批入库.
        *   自动扣减订单未执行数量.
        *   更新订单状态 (部分入库/已完成).
2.  **入库单查询**:
    *   **功能**: 按时间、供应商、物资查询入库记录.
    *   **导出**: 导出入库明细 Excel.

### 2.2 供应商管理 (Supplier)
1.  **供应商档案**:
    *   **字段**: 名称, 税号, 联系人, 电话, 地址, 评级, 状态.
    *   **功能**: 新增、修改、停用、黑名单.
2.  **绩效评估**:
    *   **维度**: 价格水平, 交货及时率, 质量合格率.
    *   **逻辑**: 系统根据订单执行数据自动评分.

## 3. 财务管理模块

### 3.1 发票管理 (Invoice)
1.  **发票录入**:
    *   **角色**: 采购员/财务.
    *   **操作**: 录入发票信息 (发票号, 金额, 开票日期) -> 关联入库单.
    *   **校验**: 发票金额 vs 入库金额 (允许误差范围).
2.  **发票认证**:
    *   **角色**: 财务.
    *   **操作**: 标记发票为“已认证/已抵扣”.

### 3.2 对账管理 (Reconciliation)
1.  **生成对账单**:
    *   **角色**: 采购员/财务.
    *   **操作**: 选择供应商 + 时间段 -> 系统自动汇总未对账的入库/发票记录 -> 生成对账单.
2.  **对账确认**:
    *   **状态**: 待确认 -> 供应商已确认 -> 财务审核通过.

### 3.3 结算付款 (Settlement)
1.  **付款申请**:
    *   **角色**: 采购员.
    *   **操作**: 关联对账单 -> 发起付款申请 (金额, 方式).
2.  **付款执行**:
    *   **角色**: 财务/出纳.
    *   **操作**: 确认付款 -> 填写流水号 -> 更新对账单状态为“已结算”.

## 4. AI 智能助手 (AI Assistant)

### 4.1 智能问答 (Q&A)
*   **功能**:
    *   基于 RAG (知识库) 回答采购制度问题 (如“合同审批流程”).
    *   基于 Text-to-SQL 回答数据统计问题 (如“上个月A供应商供货多少？”).

### 4.2 智能单据 (Smart Docs)
*   **功能**:
    *   OCR 识别发票/合同 -> 自动填单.
    *   根据订单信息自动生成合同 Word 文档.
