# PPOMS Web系统 - 开发路线图 (Roadmap)

## Phase 1: 基础设施搭建 (Week 1-2)
**目标**: 完成前后端框架搭建，打通登录流程，实现“用户管理”功能。

*   [ ] **后端**: 初始化 Spring Boot 项目，集成 MyBatis-Plus, Spring Security, JWT, Redis.
*   [ ] **前端**: 初始化 Vue 3 + Element Plus 项目，封装 Axios, Router, Pinia.
*   [ ] **数据库**: 创建 `sys_` 系列表，编写 V1.0 初始化 SQL.
*   [ ] **功能**: 实现登录 (`/login`)、退出、获取用户信息接口。
*   [ ] **功能**: 实现用户管理 (CRUD)、角色管理、菜单权限分配。
*   [ ] **部署**: 编写 Dockerfile，验证 Jenkins/GitLab CI 流水线。

## Phase 2: 核心业务 - 采购计划与任务 (Week 3-4)
**目标**: 实现从需求导入到任务分发的全流程。

*   [ ] **数据库**: 创建 `monthly_plans`, `orders`, `release_orders`.
*   [ ] **功能**: 月度计划导入 (Excel 解析) 与审批流程。
*   [ ] **功能**: 采购任务池展示，任务指派功能。
*   [ ] **功能**: 采购员工作台（查看我的任务）。

## Phase 3: 核心业务 - 订单与供应链 (Week 5-6)
**目标**: 完成订单执行、入库、发票闭环。

*   [ ] **数据库**: 创建 `order_details`, `inbound_orders`, `invoices`.
*   [ ] **功能**: 采购订单生成（关联任务/合同）。
*   [ ] **功能**: 入库单录入（关联订单，扣减数量）。
*   [ ] **功能**: 发票录入与校验（关联入库单）。
*   [ ] **AI**: 集成 Text-to-SQL，实现简单的“查订单”对话功能。

## Phase 4: 财务与合同 (Week 7-8)
**目标**: 实现对账结算与合同全生命周期管理。

*   [ ] **数据库**: 创建 `contracts`, `reconciliations`, `settlements`.
*   [ ] **功能**: 供应商对账单生成与确认。
*   [ ] **功能**: 付款申请与结算记录。
*   [ ] **功能**: 合同台账、合同执行进度追踪。

## Phase 5: 优化与验收 (Week 9)
**目标**: 系统测试、性能优化、文档完善。

*   [ ] **测试**: 全链路集成测试 (SIT)。
*   [ ] **优化**: 慢 SQL 排查，Redis 缓存预热。
*   [ ] **文档**: 补充用户操作手册。
*   [ ] **发布**: 生产环境部署上线。
